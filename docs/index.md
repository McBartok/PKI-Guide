# PKI & Certificate Flow

A short, concept-first guide for developers and engineers who use certificates (HTTPS, mTLS, signing) and want to understand **how, why, and where** they work.

## Start here

The main flow is the [Learn path](learn/index.md) (chapters 0-6).  
Use [Reference](reference/index.md) as optional deep-dive and troubleshooting material.

## Choose a goal

### New to PKI
Start with [Crash course](learn/00-crash-course.md), then continue through the [Learn path](learn/index.md).

### Need to debug a certificate issue now
Read [Trust and chains](learn/03-trust-and-chains.md), [TLS and mTLS flow](learn/04-tls-and-mtls-flow.md), and the [Debugging cheat sheet](reference/debugging-cheat-sheet.md).

### Platform/security deep dive
Follow the full [Learn path](learn/index.md), then use the [Trust failures, pinning, and case studies appendix](reference/07-trust-failures-pinning-and-case-studies.md).

## Scope

This guide focuses on developer and engineering use of certificates and TLS. It is not a complete CA operations manual, cryptographic proof text, or production PKI deployment guide.
